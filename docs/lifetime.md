# 寿命の考え方

値を計算すること、Signalが到着すること、インスタンスが生きていることは別です。

**Life Timeだけが自然寿命の期限を設定します。FCurveの長さは寿命ではありません。**
Life Timeがなければ無限です。期限に達した時点と、子や予約済み継続の終了を待って
最終的に破棄できる時点も区別します。期限後に待つものがあるからといって、
期限そのものをカーブ尺へ伸ばしたり、終了処理を何度も実行したりはしません。

Start／Loop／Endは表現のロジックです。EndRequestは利用者が処理する通知で、
受信しただけで自動的に退場アニメーションやDestroyが始まるわけではありません。
即時Endに移るか、次のLoop境界を待つかはノードで構成します。

自然Destroy、手動Stop／Reset、明示的なForce終了は同じではありません。
ForceはEnd完了を待たず対象スコープを中断し、自然Destroyを偽装して二次Spawnを
誤発火させません。描画や待機イベントの後始末はランタイム／アダプターの責務です。

TimelineでのエディタープレビューLoopと、保存・コンパイルしてエンジンで実行する
エフェクト内部のLoopも別です。グラフの確認と実エンジンでの結果を分けて確認します。

詳しい実行規約は[Spawnable Group](../Runtime/SPAWNABLE-GROUP.txt)、
[スコープ別終了](../Runtime/SCOPED-LIFECYCLE.txt)を参照してください。
