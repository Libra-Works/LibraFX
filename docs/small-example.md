# 小さな実例：生成して、動かし、消す

同梱の `Assets\Samples\Fireworks.lfxproj` を読む入口です。
サンプルは読むだけでも利用でき、エンジンへの接続や外部AIサービスは不要です。

まずルートで生成SignalとSpawnableの関係を見ます。次にSpawnableへ入り、
生成時に取り込む値と、時間に合わせて評価する値を区別して読みます。
最後にLife Timeと自然Destroy側の経路を確認します。生成時の位置を覚えることと、
生成後も外部の位置へ追従することは違います。

内部を変更する前に別名保存してください。ノードを移動して見やすくすることは
値やSignalを変更することではありません。[Flow配置](graph-layout.md)を使う場合は
対象範囲を明示し、previewの移動量・固定対象を確認してから適用できます。

チャットでは選択したノードについての質問下書きを作れます。送信は自動ではなく、
プロジェクトの共有先・内容を確認してから行います。回答中のノード参照から対象へ
移動できても、回答が作者の意図まで証明するわけではありません。

**このページは実エンジンの撮影結果ではありません。**
モデルや素材の対応付け、再生結果、終了後の後始末は専用エンジンプロジェクトで
別途確認します。撮影・文書更新の手順は[文書の再現](documentation-capture.md)を参照してください。
