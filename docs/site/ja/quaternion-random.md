# クォータニオンとシード付き乱数

更新版では、custom ノードの既定値を分岐メタデータが上書きする出力不具合を修正しています。
以前に出力したエフェクトは、編集用の `.lfxproj` から再出力してください。
既に影響を受けたバイナリーを読み込むだけでは、上書きされた元の値は復元できません。

方向ベクトルの回転や姿勢の補間には Quaternion、粒子ごとに再現可能な
初期方向・位置を与えるには Random を使います。いずれもポータブルな
C++ パラメーター実装で、GPU シェーダーノードやエンジン固有の型変換ではありません。

**更新したエディター／コンバーターと対応するランタイム／SDK が必要です。**
旧 2026.11.8 ダウンロードは、これらの UUID を含みません。
[Preview 配布ページ](https://github.com/Libra-Works/LibraFX/releases)の更新版を組み合わせてください。
回帰テストの結果だけでは、エンジン上の統合動作の確認にはなりません。

## 表現と回転規約

クォータニオンは **FloatX4 の XYZW 順**に保存し、ハミルトン積を使います。
単位回転は `(0,0,0,1)` です。FloatX4 は保存表現であって新しい意味型ではなく、
一般の4次元ベクトルをつないでも有効な回転とは限りません。
構築には **クォータニオン XYZW 合成**または**オイラー角からクォータニオン**を使い、
vector3→vector4 変換で回転を作らないでください。
成分の取得には既存の**ベクトル4分解**の名前付き X/Y/Z/W ピンを使えます。
ベクトルの回転は暗黙には行わず、**クォータニオンでベクトル回転**を使います。

角度はすべて **度（degrees）で、ラジアンではありません**。
オイラー角は `(RollX, PitchY, YawZ)`。
既存 `LbMatrixMath::makeTransform` と同じ列ベクトル規約です。

`R = Rz(Yaw) * Ry(-Pitch) * Rx(-Roll)`

- オイラー角 `(90,0,0)`：`(0,1,0)` → `(0,0,-1)`
- オイラー角 `(0,90,0)`：`(1,0,0)` → `(0,0,1)`
- オイラー角 `(0,0,90)`：`(1,0,0)` → `(0,1,0)`

一方、軸角は通常の**右手系の正方向**です。正の Roll/Pitch と同じ回転を
+X/+Y 軸の軸角で作る場合は角度を反転します。+Z 軸は Yaw と同じ符号です。

| ノード | 入力と既定値 | 出力・意味 |
|---|---|---|
| Quaternion Identity | なし | 単位回転 `(0,0,0,1)` |
| Quaternion Compose | X/Y/Z = 0、W = 1（4つの Float） | XYZW の構築。自動正規化なし |
| Quaternion Normalize | Quaternion = 単位回転 | 正規化。非常に大きい／小さい有限値にもスケーリングで対応 |
| Quaternion Conjugate | Quaternion = 単位回転 | `(-X,-Y,-Z,W)`。自動正規化なし |
| Quaternion Inverse | Quaternion = 単位回転 | `conjugate(q)/dot(q,q)`。非単位長にも対応 |
| Quaternion Multiply | A/B = 単位回転 | `A*B`。**B が先、A が後**。自動正規化なし |
| Quaternion From Euler | Roll/Pitch/Yaw = `(0,0,0)` 度 | 上記の行列規約の XYZW |
| Quaternion To Euler | Quaternion = 単位回転 | 既存行列分解と同じ規約の標準形オイラー角（度）。元と同じ数値になるとは限りません |
| Quaternion Axis Angle | 軸 = `(0,0,1)`、角度 = 0 度 | 軸を正規化し、単位長の XYZW を生成 |
| Quaternion Slerp | 開始/終了 = 単位回転、T = 0.5 | 両端を正規化し T を `[0,1]` に制限。最短回転。内積 >= 0.9995 では正規化線形補間 |
| Quaternion Rotate Vector | Quaternion = 単位回転、Vector = `(1,0,0)` | 正規化した姿勢で FloatX3 を回転。移動・拡縮なし |

Normalize・Inverse・To Euler・Slerp・Rotate Vector にゼロクォータニオンを
渡すと `InvalidArgument` になります。Axis Angle のゼロ軸も、
**角度0の場合を含めて**エラーです。Compose・Conjugate・Multiply は生の代数演算で、
ゼロを生成できますが、それが有効な回転になるわけではありません。
共役が逆クォータニオンと一致するのは単位長の場合だけです。
ジンバルロック時は既存行列分解と同様に Roll = 0 とし等価な Yaw を求めます。
符号の標準化はせず、`q` と `-q` は同じ回転です。
ちょうど180度では最短経路が2つあり、端点表現で選択が変わり得ます。

全入力は有限値が必要です。非有限入力・演算結果や表現できない大きさの逆数は
`NonFinite` となり、単位回転に置き換えません。アンダーフローでゼロになることは
あります。非常に大きい値の積はあふれ得るため、姿勢なら先に正規化してください。

## 状態を持たないシード付き乱数

すべての Random ノードに **Seed（シード）**と**Sample Index（サンプル番号）**があり、
既定値はいずれも0です。型は **符号なし32ビット整数値 `0..4294967295` を
正確に載せる Float ピン**であり、意味型 Int32 ではありません。
小数・負数・範囲外は丸めたり循環させず `InvalidArgument` にします。
Int32 からは明示的に **Int32 To Float** を通してください。

| ノード | その他の入力・既定値 | 出力 |
|---|---|---|
| Random Float | 最小 = 0、最大 = 1 | 範囲内の Float |
| Random Integer (Float)、kind は `RandomInt` | 最小 = 0、最大 = 10 | **両端を含む**整数値の Float。端点は符号付き32ビット整数 |
| Random Vector3 | 最小 XYZ = `(0,0,0)`、最大 XYZ = `(1,1,1)` | 成分別ストリームによる直方体内の値 |
| Random Unit Sphere | なし | Z・方位角の等面積標本化による単位方向 |
| Random In Sphere | なし | 立方根の半径による体積を考慮した単位球内の位置 |

最小・最大が逆なら交換し、Vector3 は成分ごとに交換します。同値ならその値です。
RandomInt の端点は `[-2147483648,2147483647]` の整数に限り、小数はエラーです。
全 signed32 範囲を扱い、棄却法を通してから剰余を取るため、
単純な `word % count` の写像による偏りを持ち込みません。
真の Int32 ピンへは **Float To Int32** で明示変換してください。
現行コールバック ABI v1 が意味型 Int32 を運べないため、
このノードは対応しているように見せかけません。

Float は `u = word / 2^32`、`0 <= u < 1` から端点の凸結合を求めます。
丸めで最大端点に達することがあります。球内・球面上の値は連続一様分布の
有限離散近似であり、暗号用途や統計的独立性の保証には使えません。

### 再現性と限界

実装バージョン1は Seed・Sample Index・成分ストリームを定義済みの
modulo-2^32 算術でハッシュします。**グローバル乱数・隠れた進行状態・
フレーム依存・評価順依存はありません。** 入力が同じなら再評価しても同じ値です。
粒子の安定した整数 ID を Sample Index に与えると、ID ごとの初期値を再現できます。
時間を進めるだけでは新しいサンプルになりません。
小数の Time をそのまま Sample Index につながないでください。

同じ実装と binary64 数値転送なら整数ハッシュ／RandomInt の写像は
エンディアン・OS・エンジンをまたいで共通です。ただし Float の端点混合は
演算融合によって最下位ビットが変わり得ます。球面生成の `sin/cos/sqrt/cbrt` と
クォータニオンの三角関数も数学ライブラリに依存します。
**異なるプラットフォームでの浮動小数点ビット完全一致は保証しません。**
安定した UUID のまま整数写像を変更するには明示的な互換性判断が必要です。

同じ Seed/Index のノードは基礎ストリームを共有します。Float・Vector3・球の
サンプルは意図的に関連があり、独立ではありません。無関係な属性には別の Seed を
使ってください。ハッシュは実質32ビットのため異なる Seed/Index の衝突や
同じ値の反復があり、サンプルの一意性や球内全域の網羅は保証しません。

## 小さな制作例

- 軸角とベクトル回転で `(1,0,0)` を +Z 周りに90度回します。
  結果は約 `(0,1,0)`。エンジン Transform や4成分への型変換とは別です。
- 2つの姿勢を From Euler → Slerp → To Euler で補間して、
  オイラー角を要求する描画ノードへ渡します。方向の回転なら XYZW のまま使えます。
- Random In Sphere の Sample Index に粒子の安定 ID を与え、Seed を固定して
  初期位置を再現します。ID を渡す粒子スケジューラーは別途必要で、
  Random ノードの追加だけで粒子シミュレーションになるわけではありません。

確認済みなのは JSON・UUID・翻訳の静的整合性です。コンパイル契約とネイティブ演算の
テストソースを追加していますが、ビルド・実行・UI操作・Undo/Redo・コピー／貼り付け・
エンジン上の描画は更新後のアプリケーションで未検証です。

任意の `QuaternionRandomCompilationTests.WriteNativeFixtures` は
`VfxProgram.Compile(...).ToBinary()` による
**内部コンパイラーからネイティブへの raw program fixture** を生成します。
拡張子は `.lfxb` ですが、統一形式の `EffectBinary` コンテナーではありません。
ネイティブテストは `Program::load` で読みます。このヘルパーは単独コンバーターの
実行ファイルを呼び出しません。fixture の実行も、コンバーター実行ファイルとの
統合動作も未検証です。
