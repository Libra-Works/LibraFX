# 困ったときの確認

近い症状から確認してください。設定は一度に1つずつ変え、同じ短い範囲を再生して比べます。
パネルの場所が分からないときは[ウィンドウ・パネル一覧](editor-reference.md)を開きます。

## 再生位置は動くのに、エフェクトが見えない

1. エンジンのプレビューに接続しているか確認します。グラフの再生位置は、描画先なしでも動きます。
2. エンジン側の画面、カメラの位置、エフェクトの大きさを確認します。接続表示だけでは描画の確認になりません。
3. **Log**を開き、最初のコンパイルエラー・シェーダーエラー・素材の参照エラーから解決します。
4. 粒子上限・毎秒の放出数・開始時の放出数・寿命を確認します。毎秒の放出も開始時の放出もゼロなら、粒子は生まれません。
5. 素材の割り当てを確認します。ローカル画像のプレビューは、エンジンへのインポートではありません。

接続と素材の設定は[接続からゲームでの再生まで](production-workflow.md)で確認できます。

## ピン同士をつなげられない

出力から入力へつなぎ、型が合っていることを確認します。
値のピンはデータ、オレンジ色のSignalは実行の合図です。
型が異なる値には変換ノード、Signalを複数へ送るときは **Sequence** を使います。
[グラフ制作の基本](authoring.md)も参照してください。

## 粒子の値を変えても反映されない

- 生まれるときの値は **Spawn**、生存中の動きは **Update**、見た目は **Draw** を開きます。
- CPUのsetterはステージイベントにつなぎます。置いただけでは実行されません。
- Spawnの変更は新しい粒子へ反映されます。初期値を比べるときは、停止して再生し直してください。
- **Emitted total**の接続がある場合は、その入力から放出数を受け取ります。コンテナの既定放出数と加算しません。

[噴水のチュートリアル](first-fountain.md)で、生成・更新・描画を分けて確認できます。

## テクスチャーのアニメーションが動かない

Spriteエディターから対象の粒子ノードへ適用し、描画設定の **Spriteエディターのアニメーションを使う** を確認します。
FPS・範囲・ループはSpriteエディター側の設定を使います。画像サイズも編集時と一致させてください。
等間隔のFlipbookなら、グリッドと開始フレームを確認します。[パーティクルのアニメーション](sprite-animation.md)で、読み込みから適用までを説明しています。

## 早く消える、途中でループする

タイムラインの再生範囲・ループと、**Life Time**ノードの寿命は別です。両方を確認します。
ルートで連続再生するGPU・Fluid2Dでは **アイドル時に自動終了** も確認してください。
Spawnableなら、生成のSignalと寿命が必要です。[時刻と寿命の用語](glossary.md#time)も参照できます。

## 書き出したものを再生できない

エディター・コンバーター・SDKを同じリリースでそろえます。
実行用の `.lfxp` を出力し、エンジンで読み込んで素材を割り当ててください。
`.lfxrm` はResource Identityの診断用マニフェストで、そのまま再生するエフェクトではありません。
編集元の `.lfxproj` も残します。[リリースノート](release-notes.md)・[一括変換](batch-conversion.md)で対応条件を確認できます。

## 接続できない、素材の一覧が空になる

対象のエンジンとプロジェクトを確認し、どちらかを再起動したら接続し直します。
素材を取得できる範囲はエンジンによって異なります。エンジン一覧が空でも、文書内の素材がないとは限りません。
別エンジンの割り当て名を流用せず、[使うエンジンの手順](production-workflow.md)を確認してください。

## 問題を報告したい

ビルド番号、エンジンのバージョン、再現する操作、期待した結果、最初のエラーを添えてください。
大きな制作シーンより、小さくした再現用プロジェクトがあると調べやすくなります。
ログ共有の前に、個人のパスや接続の招待情報が入っていないか確認します。
