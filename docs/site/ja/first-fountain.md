# 最初の噴水を作る

小さなグロー玉が上へ飛び出し、重力で曲がって落ち、消えていく噴水を作ります。
前半はサンプルを触るコース、後半は空のグラフから作るコースです。JSONやコードは書きません。

## 用意するもの

- `CpuFountain.lfxproj` を含む更新版LIBERA FX。
- 実際の描画を確認するための、同じ版のエンジン連携パッケージ。
- 書き込み可能な作業フォルダー。

画面に迷ったら[はじめての画面操作](workspace-tour.md)を開いておきます。
初めてのエンジン接続は[制作フロー](production-workflow.md)を先に済ませてください。
接続したプレビューでパーティクルが表示されるところまで確認してから、値を変えると分かりやすくなります。

## コースA：サンプルを触って理解する

### 1. サンプルを開く

**File → Open** で `Assets/Samples/CpuFountain.lfxproj` を開きます。
**Save As** で `MyFountain.lfxproj` などの名前にして保存します。

**確認：** 親グラフに `Fountain` と説明のコメントがあります。
ノードの下部には種類としてCPU Particleが表示されます。

### 2. 粒子の量を変える

`Fountain` を選び、インスペクターで **既定の毎秒放出数**を `300` から `60` にします。
再生範囲は **Start = 0、End = 600、FPS = 60** にして再生します。

**確認：** 1秒に生まれる粒子が減り、一本ずつの動きを追いやすくなります。
粒子上限と毎秒放出数は別の設定です。上限だけを増やしても放出量は増えません。

### 3. 上向きの勢いを変える

1. `Fountain` をダブルクリックします。
2. **生成（Spawn）→ ステージのグラフを開く** を押します。
3. サンプル内の `Upward velocity` ノードを選びます。
4. `b` の **Y** を `5` から `3` にします。XとZは `0` のままです。

**確認：** 噴水の高さが低くなります。Yが上方向です。
Unity用・Unreal用で上向きの値を書き直す必要はありません。

横方向の広がりは `Horizontal spread` の値で変えられます。
まずは上下の勢いだけを変え、違いを確認してから広がりを調整しましょう。

### 4. 落ちる強さを変える

1. 上部のパンくずでCPU ParticleのFlowへ戻ります。
2. **更新（Update）→ ステージのグラフを開く** を押します。
3. `Velocity + gravity` を選びます。
4. **Acceleration** のYを `-9.81` から `-4` にします。

**確認：** 下へ引かれる力が弱くなり、よりゆっくり落ちます。
`0` にすると重力なしで進みます。負のYは下向き、正のYは上向きです。

### 5. 大きさと寿命を変える

生成のグラフへ戻り、`Glow diameter` の **Size** を `(0.14, 0.14)` から `(0.08, 0.08)` にします。
続いて `Particle lifetime` の **Life** を `3` から `1.5` にします。

**確認：** 玉が小さくなり、早く消えます。
このサンプルには寿命に合わせて薄くする処理も入っているので、消えるまでの変化も短くなります。
動いている途中に変えた生成時の設定は、すでに生まれた粒子へはさかのぼって適用されません。
最初から比較したいときは、停止して再生位置を先頭へ戻します。

### 6. グロー玉の設定場所を確認する

CPU ParticleのFlowへ戻り、**描画（Draw）→ 描画設定を編集** を押します。
**テクスチャーの種類 → グロー玉** が選ばれていることを確認します。
これは中心から端へ透明になる生成画像です。画像ファイルを用意する必要はありません。

### 7. スロー再生と移動で確認する

再生速度を `0.25` にして、曲がり方と消え方を確認します。比較後は `1` に戻します。
**プレビュー移動**で円運動や球面移動を選ぶと、移動するエフェクトの見え方を確認できます。
半径はメートル単位です。静止へ戻すと移動を解除します。

最後に保存します。ここまでできれば、放出量・初速度・重力・サイズ・寿命の設定場所を確認できています。

## コースB：空のグラフから組み立てる

### 1. CPU Particleを置く

**File → New** で新しいグラフを作ります。
ノード一覧で **CPU Particle** を検索し、中央へドラッグします。
親のインスペクターで次の値にします。

| 項目 | 値 |
| --- | --- |
| 粒子上限 | `2048` |
| 既定の毎秒放出数 | `120` |
| 開始時の放出数 | `0` |

このコースでは、親の **Emitted total** ピンには何もつなぎません。
何もつながっていない場合に、いま設定した毎秒放出数を使います。

### 2. 生まれるときの速度を決める

CPU Particleを開き、生成のグラフを開きます。
最初からある **Set Particle Velocity／粒子の速度を設定** を選び、**Velocity** を `(0, 5, 0)` にします。
ステージイベントから、このノードへオレンジ色の線がつながっていることも確認します。

### 3. 寿命とサイズを設定する

生成のグラフに次の2つを追加します。

- **Set Particle Life／粒子の寿命を設定**：Lifeを `2`。
- **Set Particle Size／粒子のサイズを設定**：Sizeを `(0.1, 0.1)`。

オレンジ色の端子を、次の順にドラッグして接続します。

`CPU Stage Event → Set Particle Velocity → Set Particle Life → Set Particle Size`

送り元の **Then** から、次のノードの **Set** へ接続します。
ノードを置くだけでは寿命やサイズの設定は実行されないので、線も確認します。

### 4. 生きている間の動きを決める

CPU ParticleのFlowへ戻り、更新のグラフを開きます。
最初からある **Move Particle／粒子を移動** のAccelerationを `(0, -9.81, 0)` にします。
ステージイベントから移動ノードへ、オレンジ色の線がつながっていればOKです。

### 5. 見た目を選んで再生する

描画設定を開き、**テクスチャーの種類 → グロー玉** を選びます。
親グラフへ戻り、保存してから接続先のプレビューで再生します。

**確認：** 小さな玉が毎秒120個ずつ上へ出て、曲がって落ち、2秒で消えます。
すべて同じ真上へ飛ぶのは、このコースでは横向きのランダムさを加えていないためです。
広がりや透明度の変化を加えるときは、コースAのサンプルと見比べてください。

## うまくいかないとき

| 状態 | 確認するところ |
| --- | --- |
| グラフは開けるが何も描かれない | エンジンとの接続、プレビュー画面、再生状態を確認します。 |
| 生成・更新・描画の設定が見つからない | 親グラフでCPU Particleをダブルクリックします。 |
| 設定ノードを追加しても変化しない | オレンジ色の実行の線につながっているか確認します。 |
| 上向きに出ない | 生成時のVelocityのYが正になっているか確認します。 |
| 落ちてこない | 更新側のMove ParticleのAccelerationのYを負にします。 |
| 途中で消えすぎる | Spawn側のLifeを確認します。タイムラインのEndとは別の設定です。 |
| 設定値が変えられない | ノード・項目のロックと、接続済みの入力を確認します。 |
| 上限エラーになる | 放出数と寿命を下げるか、粒子上限を増やします。目安は毎秒放出数×寿命です。 |

次は[CPU Particleの詳しい説明](cpu-particles.md)、
[ウィンドウの使い方](workspace-tour.md)、[標準ノード図鑑](node-reference.md)へ進めます。
