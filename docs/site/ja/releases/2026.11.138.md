# 2026.11.138 Preview

公開日: 2026-11-25 · [このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.138) · [リリースノート一覧](../release-notes.md)

## 主な変更点

- **コンパイル済みパッケージを `.lfxp` に一本化:** エディター、コンバーター、MCP、ライブプレビューは `.lfxp`（パッケージ形式 13）だけを出力・読み込みます。旧 `.lfxb`、単一グラフ用の生プログラム API（`libra_program_create*`、`libra_session_submit_program`）、旧プレビュー用コンポーネントは削除しました。編集用プロジェクトは引き続き `.lfxproj` です。古いプロジェクトデータは開いたときに移行されます。
- **ライブプレビューのパラメーターデルタ:** ライブプレビュー中の値変更はパラメーターデルタで送ります。倍精度、一括検証、既定値へのリセット、列挙型、行列、F-Curve に対応し、ネストしたグラフやグループのオーバーライドにも反映されます。Signal キーなどデルタで表せない変更はパッケージ全体を再送します。
- **エンジン側の入口:** Unreal は `ULibraEffectComponent` を唯一のエフェクトコンポーネントとし、`.lfxp` を再生します。Unity と Godot も `.lfxp` のみを読み込みます。GPU パーティクルのマニフェストは現行スキーマのみです。
- **リルートとワイヤー編集:** `Add reroute` が動作するようになりました。ワイヤーを選択して一括削除やリルートの一括挿入ができ、元に戻すこともできます。ネストしたグラフへドラッグする間もワイヤーがノードの手前に表示されます。MCP にリルートの追加・削除・確認ツールを追加しました。
- **階層ナビゲーション:** Houdini 風のパンくずと、戻る／進むの履歴を追加しました。
- **Transform ノード:** 任意の `Parent` 行列入力を追加し、`Mul` ノードを足さずに親子関係を作れます。未接続の場合の動作は変わりません。
- **MCP ガイド:** AI アシスタントとの接続方法と会話例をまとめた [MCP ガイド](../mcp-guide.md) を追加しました。

## アップグレード時の注意

- 互換性のない更新です。デスクトップエディター、`LiberaFxConverter`、各エンジン SDK（`LibraForUnity` / `LibraForGodot` / `LibraForUnreal` / `LibraSDK-source`）を必ず同じ `2026.11.138` に揃えてください。
- 更新前にプロジェクトをバックアップしてください。以前に書き出した `.lfxb` や古い `.lfxp` はこのランタイムでは読み込めないため、このエディターまたはコンバーターで `.lfxproj` から再エクスポートしてください。
- Unreal Engine 5.7（Windows x64）では、ビルド済みの `LibraForUnreal-2026.11.138-UE5.7-win64.zip` を使うか、`Install-LibraRuntimeForUnreal.ps1` でソースからインストールしてください。UE 5.8 用のバイナリは含みません。
- macOS arm64 版アーカイブは未署名・未公証です。
