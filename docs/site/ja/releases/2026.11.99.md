# 2026.11.99 Preview

**2026年11月24日公開。** 2026.11.87の後継Previewです。
[このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.99)
／[リリースノート一覧](../release-notes.md)

## 主な変更

- **Unity / Godot マルチプラットフォームバイナリ配布：** `LibraForUnity-2026.11.99.zip` と
  `LibraForGodot-2026.11.99.zip` に Windows x64 / Linux x64 / macOS ARM64 の
  ネイティブライブラリと対応する `.meta` / `liberafx.gdextension` 設定を同梱し、
  CI でのバイナリ検証を通過しました。
- **コンテンツウィンドウと Resource Identity の統一：** Unity（`Assets/`・`Packages/`）と
  Godot（`res://`）でも `"assets"` ケーパビリティによる一覧・フォルダ・詳細・サムネイル取得に
  対応しました。Godot では `res://` の Resource Identity（`godot.res-path.v1` /
  `godot.shader-parameter.v1`）および `.lfxrm` 出力にも対応しています。
  [制作からゲーム組み込みまで](../production-workflow.md)をご覧ください。
- **再生制御と GPU ブレンドの統一：** Unity の `LiberaFxSpawnableComponent` に
  `Pause()` / `Resume()` / `IsPaused`、Godot の `LibraEffectPlayer` に
  `pause()` / `resume()` / `is_paused()` を追加し、Unity の `LibraGpuBillboard.shader` で
  `builtin:unlit-additive`（加算ブレンド）に対応しました。
- **Unreal `BuildPlugin` 対応とローカル検証ランナー：** `LibraRuntimeForUnreal` の
  IWYU ヘッダ不足と `#if WITH_EDITOR` ガードを修正し、`RunUAT BuildPlugin`
  （`UnrealEditor` + `UnrealGame`）に対応しました。あわせて一括ローカル検証用の
  `Tools/Invoke-LocalVerification.ps1` を追加しました。

## 更新手順

1. 編集元のプロジェクトを残し、エンジンのアセット割り当てと既存の導入物をバックアップします。
2. 上のダウンロード先から、**2026.11.99のエディター・コンバーター・SDKをまとめて更新**します。
   Unity プラグインの重複登録を避け、既存アセットの `.meta` を維持してください。
3. Unity の `works.libra.liberafx` または Godot の `liberafx` アドオン（Windows x64 /
   Linux x64 / macOS ARM64 同梱）をコピーします。Unreal プラグインは配布物上はソース形式で、
   必要に応じてローカルの `Tools/Build-UnrealBinaryPlugin.ps1` からバイナリープラグインを生成できます。
4. 検証用プロジェクトでエフェクトを再出力し、使用するエンジンとプラットフォームで確認します。
   macOS のエディターは未署名・未公証です。
