# 2026.11.72 Preview

**2026年11月22日公開。** 2026.11.63の後継Previewです。
[このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.72)
／[リリースノート一覧](../release-notes.md)

## 主な変更

- **SpriteエディターのアニメーションをCPU・GPUパーティクルへ適用できます。**
  セル・コマ順・表示時間・再生範囲・FPS・ループに対応します。複数パーツの合成では、
  表示順と位置・回転・拡縮のキーも使えます。設定の保存・再編集・Undo/Redoに対応し、
  無効にしても編集元を残します。等間隔のFlipbookとは別の設定です。
- **UnityのGPU描画をカメラ描画時に投入します。** 計算と描画を分け、時間が進まない間も
  最後の状態を表示します。カメラの描画で粒子計算や年齢が進むことはありません。
  描画レイヤーによる除外・停止後の消去・再再生の確認手順も追加しました。
- **準備済みホストと複数インスタンスの共有実行をエンジン連携へ接続しました。**
  対応するUnity・Unreal・Godotの経路でCoreホストを再利用し、対象インスタンスをまとめて実行します。
  粒子の属性別配列、階層、Coreプロシージャルメッシュエミッター、コールバックの実行方針にも対応します。
  安全でないコールバックは必要なスレッドに残し、描画全体のメモリ確保ゼロを保証するものではありません。
- **準備するホスト数の既定値は256**です。パッケージ／設定ごとの値で、準備のワーカー数には上限があります。
  既存のシーンやアセットに保存済みの値は維持します。

操作は[CPUパーティクル](../cpu-particles.md)・[GPUパーティクル](../gpu-particles.md)、
導入は[ゲームエンジンとの連携](../engine-integration.md)をご覧ください。

## 更新手順

1. 編集元のプロジェクトを残し、エンジンのアセット割り当てをバックアップします。
2. 上のダウンロード先から、**2026.11.72のエディター・コンバーター・SDKをまとめて更新**します。
   古いnative libraryと新しいスクリプトを混在させたり、Unityプラグインを重複登録したりしないでください。
3. エディターから再出力します。SpriteアニメーションにはCPU描画メタデータ **4**、
   またはGPU executable payload **4** とrenderer bindings **2**が必要です。
   粒子バッファーと計算カーネルの形式は変わりませんが、旧SDKは新しいメタデータを読めません。
4. 別の検証用プロジェクトで、読込・Play・Stop・再再生を確認します。
   再利用するホストはロード中に準備してください。Unrealの配布物はソース形式なので、Editor targetを再ビルドします。

Unity 7 alphaで同梱シェーダーを使う場合は、起動時に `-enable-builtin-rp-fallback` が必要です。

## この版で確認した範囲

- 配布CIはMCP操作、WindowsのAddressSanitizerによる生成データの検査、Clang／CTest、
  3種類のデスクトップ配布物とエンジンSDKの全ジョブが成功しました。
- ダウンロードした配布物のバージョン・ソース・ハッシュ・導入構成・実行権限と、MSIのProductVersionを確認しました。
  Core SDKの単独ビルド、配布Converterの最適化、native DLLのプールAPI検査も通過しました。
- **Unityの配布SDK：** Windows／7000.0.0a16／D3D11／RX 6700 XT。
  Built-Inと検証用SRPのPlay Modeで、CPU・GPUのコマ切替・合成・無効設定・カメラの描画レイヤー・
  時間停止中の再描画・Stop・再再生を実画面で確認しました。
- **Godotの配布SDK：** 4.7.2／Vulkan Mobile／RX 6700 XT。
  CPU・GPUのコマ切替・パーツ変形・time scaleゼロでの停止・消去・再再生を確認しました。
- **Unrealのソースプラグイン：** UE 5.7／D3D11のローカル検査で、CPUのシーン適用・再再生と、
  GPUビルボードの実描画・インポート・全パーツ非表示を確認しました。

UnityのURP／HDRP・Player／IL2CPP、Unrealのパッケージ済みアプリ、コンソールや他の環境を保証する検査ではありません。
Unity／Godot同梱のnative binaryはWindows x64用です。Niagaraとの性能比較結果ではありません。
