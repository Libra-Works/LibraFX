# 2026.11.87 Preview

**2026年11月23日公開。** 2026.11.72の後継Previewです。
[このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.87)
／[リリースノート一覧](../release-notes.md)

## 主な変更

- **Flexible Plane Point List：** ノードやインスペクターで位置ピンを増減できます。
  ピンを減らしたときの接続解除もUndo/Redoできます。Flexible Plane Drawから
  プロシージャルテクスチャ・マテリアルの接続やホストのマテリアルパラメーターも出力できます。
  [フレキシブルプレーン描画](../flexible-plane-draw.md)をご覧ください。
- **検索：** ノード追加とエニシング検索で、表示言語に加えて英語の名前でも探せます。
- **GPUパーティクルのサンプル：** Curl NoiseとTurbulenceによる粒子雲と、
  Fluid2Dの速度で粒子を運ぶサンプルを追加しました。
  [GPUパーティクル制作](../gpu-particles.md)ではノードでの調整方法を説明します。
  記載した見た目は目標であり、この版での実エンジン描画の確認結果ではありません。
- **エディターとSDK配布：** Timeline・グラフのズーム・ログを改善しました。
  Unityの配布物にはWindows x64／Linux x64／macOS ARM64のnative bridgeを含みます。
  UnrealのソースSDKにはエンジン版ごとのバイナリープラグイン作成補助を追加しました。

## 更新手順

1. 編集元のプロジェクトを残し、エンジンのアセット割り当てと既存の導入物をバックアップします。
2. 上のダウンロード先から、**2026.11.87のエディター・コンバーター・SDKをまとめて更新**します。
   Unityプラグインの重複登録を避け、既存アセットの `.meta` を維持してください。
3. UnityのパッケージまたはGodotのアドオンをコピーします。Godot同梱のnative bridgeは
   Windows x64用で、他の環境では別途ビルドが必要です。Unrealのプラグインはソース形式で、
   プロジェクトのEditor targetの再ビルドが必要です。バイナリー作成補助には別途Unrealの
   インストールが必要で、選択したエンジン版用のバイナリーを作成します。
4. 検証用プロジェクトでエフェクトを再出力し、使用するエンジンとプラットフォームで確認します。
   macOSのエディターは未署名・未公証です。

## この版で確認した範囲

- 配布CIはMCP操作、WindowsのAddressSanitizerによる生成データの検査、
  LinuxのClang／CTest、3種類のデスクトップ配布物とエンジンSDKの全ジョブが成功しました。
- 取得した配布物のバージョン・ソース・SDKのハッシュ・導入構成・デスクトップの起動ファイル・
  Unixの実行権限・MSIのProductVersionを確認しました。Unrealの隠し管理ファイル、
  Unity／Godotのコピー用ファイルとnative binaryも確認しています。配布物には
  `SHA256SUMS.txt` を含みます。

このリリースで新たに実エンジン描画、UnrealBuildTool、完成したゲームやコンソールを
確認したわけではありません。最終的な見た目と組み込みは使用する環境で確認してください。
