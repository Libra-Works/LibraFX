# 2026.11.123 Preview

**2026年11月24日公開。** 2026.11.99の後継Previewです。
[このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.123)
／[リリースノート一覧](../release-notes.md)

## 主な変更

- **グラフエディター & F-Curve UI/UX 改善：**
  - 右クリックの `+ Add node` をモーダルウインドウではなく `Add node -> Category -> Node` のカスケードサブメニューに変更しました。
  - グラフ配線を整理できる `Reroute` ノード（`InsertRerouteOnConnection` / `RerouteLowering`）を追加しました。
  - MCP・自動レイアウトでの 4 列折り返しを廃止して左から右への横長フロー配置に統一し、Signal ピンを Parameter ピンより上に並べるようにしました。
  - F-Curve エディターのパン操作を Graph エディターと同じ `Right` / `Middle` ドラッグに統一し、Procedural ワークスペースのプレビュー表示不具合とグローバルファイルショートカット（`New` / `Open` / `Save` / `Save As` / `Export`）を整備しました。
- **プロシージャルスフィアテクスチャ & パーティクル初期値整理：**
  - `ParticleTextureSource` から組み込み `RadialGlow` を外し、新規 `CpuParticleSpriteDraw` の `assetPath` 初期値を空 `""` に変更しました（既存 `.lfxproj` のコンパイル互換は維持）。
  - 再利用可能な **スフィアグロー（Sphere Glow）** プロシージャルテクスチャグループアセット（`Assets/Modules/c2000000000040008000000000000001.lfxgroup`）を追加しました。
- **アプリ内アップデートチェック機能：**
  - **Help -> Check for updates** および起動時自動チェックを追加し、リリースノート表示と **今すぐ更新 / 後で / このバージョンをスキップ** を選択できるようにしました。
- **アトミック保存 & クロスエンジン受け入れ確認：**
  - プロジェクト・ストレージ保存をアトミック化し、LIBERA FX・Unity・Godot 4.7.2・Unreal Engine 5.7 での一連の動作確認を完了しました。

## 更新手順

1. 編集元のプロジェクトを残し、エンジンのアセット割り当てと既存の導入物をバックアップします。
2. 上のダウンロード先から、**2026.11.123のエディター・コンバーター・SDKをまとめて更新**します。
   Unity プラグインの重複登録を避け、既存アセットの `.meta` を維持してください。
3. `LibraForUnity-2026.11.123.zip`、`LibraForGodot-2026.11.123.zip`、または
   `LibraForUnreal-2026.11.123-UE5.7-win64.zip` をご利用ください。
4. 検証用プロジェクトでエフェクトを再出力し、使用するエンジンとプラットフォームで確認します。
   macOS のエディターは未署名・未公証です。
