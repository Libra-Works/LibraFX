# 2026.11.128 Preview

公開日: 2026-11-24 · [このバージョンをダウンロード](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.128) · [リリースノート一覧](../release-notes.md)

## 主な変更点

- **GPU パーティクル F-Curve (`GpuOp.FCurve`):** 65 サンプル LUT / `LibraGpuEvalCurve_*` シェーダー出力、既存バイトコード命令へのローワリング（ネイティブ ABI 互換維持）、および GPU ワークスペースインスペクター内のインタラクティブな `GpuCurveCanvas` を追加しました。
- **パーティクル Material / ProceduralMaterial 対応:** CPU・GPU パーティクルで `Material` および `ProceduralMaterial` をサポートし、エディタ・コンパイル・Resource Identity・Unity / Unreal / Godot 各統合へ反映しました。
- **プロシージャルプレビュー・テクスチャ改善:** `NormalMap`（`LIBRA_PIXEL_NORMAL_MAP = 32`）、`Radial -> Invert -> Saturate` のデフォルト構成、3D モデルプレビューの UV チェッカーボード表示（`ProceduralMeshPreviewView`）、入力時の即時プレビュー反映、チェッカーボード切替、ドラッグ並べ替え・`Delete` 削除、Shape UI からの `Ribbon` 非表示（`Plane` 既定）を追加・調整しました。
- **エディタ・グラフ UI の改善:** 階層移動時のカメラ状態保持、ピン接続時の二重ハイライト修正（`PortSnapFeedback`）、サンプルプロジェクトの `ProceduralTexture` 化、履歴の `Delete` キー削除、内部ノードを持つノードの折りたたみ時右下リサイズ、Graph ノード下部のノード名表示、待機中メッセージ（`Choose a node output...`）の非表示化、右クリックメニューへのグラフノード追加を実装しました。
- **Unreal / Godot ネイティブビルド修正:** Unreal 用に不足していた 9 個の `LibraRuntimeCore/Private` ラッパー `.cpp` を追加（`Verify-UnrealPluginPackaging.ps1` で網羅チェックを自動化）し、Godot の `LibraFxGodotRender.cpp` における `SpawnableScopeKind::Instance` / `scope.containerId` 参照を修正しました。

## アップグレード時の注意

- デスクトップエディタ・`LiberaFxConverter`・各エンジン SDK（`LibraForUnity` / `LibraForGodot` / `LibraForUnreal` / `LibraSDK-source`）は必ず同じ `2026.11.128` に揃えて更新してください。
- 更新前に既存プロジェクトのバックアップを推奨します。macOS arm64 版アーカイブは未署名・未公証です。
- Unreal Engine 5.7 (Win64) ではビルド済みの `LibraForUnreal-2026.11.128-UE5.7-win64.zip`、またはソースからの `Install-LibraRuntimeForUnreal.ps1` をご利用ください。
