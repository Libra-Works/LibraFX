# はじめての画面操作

このページでは、サンプルを開きながら「どの画面で何をするか」を確認します。
コードやJSONを書く必要はありません。続いて[噴水を作る](first-fountain.md)へ進むと、
粒子を上に飛ばし、重力で落とすところまで体験できます。

## 1. サンプルを開いて、自分の作業用に保存する

1. **File → Open** を選びます。
2. エディターの配布フォルダーにある `Assets/Samples/CpuFountain.lfxproj` を開きます。
3. **File → Save As** で、書き込み可能な自分のフォルダーへ別名保存します。

**確認：** ドキュメントのタブが開き、中央に `Fountain` というノードが見えれば準備完了です。
`CpuFountain.lfxproj` が見つからない場合は、このサンプルを含む更新版Previewを使ってください。

## 2. 中央のグラフで、編集するものを選ぶ

![グラフを中央に配置したLIBERA FXのワークスペース。周囲に編集パネルがある](../images/editor/workspace.png)

画像は画面配置の例です。開いているサンプルによってノードの内容は変わります。

1. `Fountain` を1回クリックします。
2. 選択枠が付くことを確認します。
3. ノードのタイトルと下部の種類表示を見比べます。自分で名前を変えても、種類表示で
   **CPU Particle** だと分かります。

キャンバスが動かしにくい場合は、**Edit → Settings** のショートカット設定で
パン操作とズーム操作を確認します。変更できる操作なので、ここでは固定のマウスボタンを前提にしません。

## 3. インスペクターで数値を変える

インスペクターは「今選んだものの設定表」です。

1. **Window → Inspectors** からインスペクターを開きます。
2. `Fountain` を選び、**既定の毎秒放出数**を探します。
3. 数値を `300` から `60` に変え、Enterを押すか別の欄をクリックします。
4. **Edit → Undo** で元へ戻してみます。

**確認：** 同じノードを選んだまま、設定値が戻ります。描画の違いはプレビューで確認します。

値を編集できないときは、インスペクターの固定ボタン、ノードや項目のロック、
その項目につながっている線を確認してください。接続した項目は、線の送り元が値を決めます。

## 4. CPU Particleの中に入って、戻る

1. `Fountain` をダブルクリックします。
2. **生成（Spawn）・更新（Update）・描画（Draw）** のカードを確認します。
3. 生成カードの **ステージのグラフを開く** を押します。
4. ノードが増えたら、画面上部のパンくずで今いる階層を確認します。
5. パンくずで親のCPU Particleを選ぶとFlowへ戻り、さらに親を選ぶと最初のグラフへ戻ります。

生成は「生まれるときの設定」、更新は「生きている間の動き」、描画は「見た目の設定」です。
最初はこの3つだけ覚えれば大丈夫です。

## 5. ノード一覧と検索で、必要な道具を探す

1. **Window → Node List** を開きます。
2. 検索欄に `CPU` や `速度` と入力します。表示言語に関係なく、英語の `Velocity` や分類名でも検索できます。
3. 使いたいノードをグラフへドラッグします。
4. よく使うノードの星を押すと、お気に入りに登録できます。

既定の `Ctrl+P` で開く**エニシング検索**は、ノードだけでなくコマンドやアセットも探します。
設定でショートカットを変えている場合は **Edit → Search anything** から開けます。

ノードの丸い端子から互換性のある端子へドラッグすると接続できます。
オレンジ色の線は「実行する順番」、数値や色の線は「使う値」を渡します。
置いただけで実行されない設定ノードは、オレンジ色の線にもつなぎます。

## 6. コンテンツで、サンプルや画像を探す

コンテンツ画面は、素材の一覧です。グラフ上のノード一覧とは用途が異なります。

1. **Window** メニューからコンテンツ／アセットのパネルを開きます。
2. **プロジェクト・ローカルのリソース**タブを選びます。
3. **ローカル**を選び、フォルダーボタンで `Assets/Samples` を指定します。
4. 更新ボタンを押し、`CpuFountain` を選びます。
5. 右側でグラフの内容を確認し、**エフェクトを開く**を押します。

画像を選んだ場合は画像の確認、グループを選んだ場合は現在のグラフへの挿入になります。
エンジンの素材を使うときは、**接続中のエンジンアセット**タブで接続先を選び、
検索・選択・割り当てを行います。一覧に見えるだけでは、選んだノードへの割り当ては完了していません。

大量の素材がある場合、エンジン側は32件ずつ、物理フォルダーは128件ずつ表示します。
選択した素材の取得を優先し、一覧のいま見えている行のサムネイルも順に取得します。
スクロールすると新しく見えた行を対象にし、画面外の行は後回しにします。
一覧用の先行取得は同時に1件、画像のキャッシュはブラウザーごとに最大64件です。

Unreal側の取得対象を絞るには、**エンジンのコンテンツ取得範囲**を開き、
**フォルダー一覧を取得**を押します。`/Game`を選んで**選択フォルダーを開く**を押し、
対象の場所までたどって**このフォルダーを使う**を押します。サブフォルダーも対象です。
**すべてのフォルダー**で制限を解除できます。検索欄の横のフォルダーボタンなら、
選択した素材の親フォルダーをそのまま対象にできます。
絞り込みはエンジン側で件数集計・ページ分割より前に行うため、タグ付けは不要です。
登録済みエンジンプロジェクトではIDごとに設定をローカル保存し、未登録なら接続中だけ保持します。
エンジン内の情報を参照する設定であり、素材ファイルのコピーは行いません。
この操作には対応版のUnrealアダプターが必要です。

## 7. タイムラインを再生して、プレビューを見る

1. **Window → Timeline** を開きます。
2. 再生範囲を **Start = 0、End = 600、FPS = 60** にします。これで10秒の範囲になります。
3. 接続したゲームエンジンのプレビュー画面を開きます。
4. 再生ボタンを押します。一時停止し、再生位置を動かしてみます。
5. **再生速度**を `0.25` にすると、ゆっくり動きを確認できます。通常速度は `1` です。

グラフ画面の再生位置が動いても、エンジンと接続していなければ粒子の描画は表示されません。
最初の接続は[エンジンとの接続手順](production-workflow.md)を参照してください。

## 8. 作業を戻す、階層から探す、困ったところを確認する

| やりたいこと | 開く画面 | 最初の操作 |
| --- | --- | --- |
| ひとつ前へ戻す | Edit → Undo | 直前の編集を戻します。Redoでやり直せます。 |
| もっと前の状態へ戻す | History | 履歴の項目を選びます。圧縮ブロックはクリックして中を開きます。 |
| キャンバスで見失ったノードを探す | Outliner | 名前から選びます。子グラフがあるものは階層も確認します。 |
| 時間で変わる数値を調整する | F-Curve | 編集するカーブを選び、キーの位置や形を変えます。 |
| 色を選ぶ | Inspectorの色欄 | 色見本を押し、色と透明度を調整します。 |
| プロシージャル画像や形を確認する | 対応ノードのFlow | 左の処理を選び、ローカルプレビューを見ながら値を変えます。 |
| 接続や描画の問題を調べる | エンジン接続、Log | 接続状態と直近のメッセージを確認します。 |
| 重さを調べる | Profiler | 操作や再生と、計測結果の変化を見比べます。 |
| 素材の参照元を探す | Asset References | 素材を選び、使っている箇所を確認します。 |
| 表示や操作を自分向けに変える | Settings | 外観・言語・ショートカットを確認します。 |

各パネルの詳細は[画面リファレンス](editor-reference.md)にあります。
次は[噴水を作る](first-fountain.md)で、生成・更新・描画を実際に編集してみましょう。
