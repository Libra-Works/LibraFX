## 値とシグナルを接続する

**Parameter** ピンは Float、Vector3、Color、Matrix などの型付きデータを渡します。
**Signal** ピンは数値ではなく実行イベントを渡します。型の合うピンを接続し、
型が異なる場合はカタログにある明示的な変換ノードを選びます。Signal を分岐したい
ときは **Sequence** を挟み、一つの出力ピンにつき一つの送り先を接続します。
Signal の入力は独立した複数の到着を受け取れます。

[Afterimage Gate](afterimage-gate.md) のコピーで試すなら、Sequence と水色の残像の間の
Delay の秒数を変え、同じ範囲を再生します。最初の点火はそのままで、二つ目の合図だけが移動します。

**Flexible Plane Point List** のように可変数のピンを持つノードでは、ノード上と
インスペクター上の **+** / **-** ボタンでピン数を増減できます。ピンを減らして
接続が外れた場合も、1 回の操作として元に戻す／やり直しができます。

## 時刻・カーブ・寿命を使い分ける

- **Time** は実行スコープの時刻です。Spawnable インスタンス内では生成後のローカルな
  時刻になり、**Effect Age** はエフェクト全体の時刻を読み取ります。
- **F-Curve** は入力を数値に対応づけます。アニメーションに使い、寿命を延ばすためには
  使いません。インスペクターでカーブを選び、F カーブパネルでキーを編集します。
- **Life Time** は寿命の期限を決めます。期限に達した時点で、子や待機中の処理が必ず
  全部なくなるわけではありません。対象のスコープに合った自然終了・強制終了を使います。
- **Timeline** の Signal キーは時刻付きの到着です。グラフに作成したキーと、
  エディター側のプレビュー再生範囲・速度・ループは区別してください。

## Group を選ぶ

| やりたいこと | 使うもの |
| --- | --- |
| グラフをまとめ、選んだピンを外部へ出す | **Graph Group** と Group Input / Group Output |
| 独自の時刻と寿命を持つ子インスタンスを生成する | **Spawnable Group** と Spawn の入出力 |
| 再利用する版を共有する | 現在のプロジェクトの Group ディレクトリに置いた Group アセット。更新内容を確認してから適用します。 |
| 同梱の移動・向きの機能を使う | ノード一覧の標準 Group を開き、公開ピンを確認してから接続します。 |

通常の Group はインスタンスの生成には使いません。共有アセットのロックは構造を
保護するもので、インスタンスごとに設定する公開値には影響しません。

## グラフをエンジンで再生する

ソースを `.lfxproj` として保存します。エディターの **VFX を書き出す...** では
`.lfxb` パッケージが生成されます。コンバーターも同じ形式を使い、単純なグラフと
Spawnable で出力を選び分ける必要はありません。取り込みにはエディターと同じリリースの SDK を使ってください。
旧 `.lfxp` と旧バイトコード単体の `.lfxb` は読み込み互換として残し、新規の出力先には使い分けません。
テクスチャ、マテリアル、メッシュはエンジンのプロジェクト側で割り当ててください。
ルートやインスタンスの名前付き Game I/O は、グラフ内部の接続とは別です。
導入、出力の確認、スクリプトや独自 C++ ノードによる拡張は
[ゲームエンジンとの連携](engine-integration.md)を参照してください。

再生できないときは、グラフのコンパイル、エンジンでのパッケージ読み込み、
出力イベントの確認、描画リソースの割り当てを順に切り分けます。
描画できたかどうかは、エンジン上に実際のフレームが表示されたことを確認します。
