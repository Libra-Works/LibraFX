# MCP クライアントを接続する

LIBERA FX は、現在の制作グラフをローカルの Model Context Protocol（MCP）サーバーで公開します。MCP クライアントからグラフを確認・編集できます。これはエンジンのライブプレビュー接続とは別の仕組みです。編集対象のドキュメントをアクティブにして、エディターを起動したままにしてください。

## 安全に接続する

既定の Streamable HTTP エンドポイントは次のとおりです。

```text
http://127.0.0.1:8765/mcp
```

サーバーは loopback のみで待ち受けます。LIBERA FX と同じコンピューター上で MCP クライアントを実行してください。別のコンピューターやリモート／クラウドのクライアントから、エディターのリスナーへ接続することはできません。すべてのリクエストに `X-LiberaFx-Token` ヘッダーが必要です。ブラウザー由来の Origin リクエストは拒否されます。

1. LIBERA FX で **表示 → MCP 接続...** を選びます。**MCP 接続**パネルに、現在の **Streamable HTTP エンドポイント**と `X-LiberaFx-Token` が表示されます。
2. **トークンを表示**を選び、隣の **コピー**ボタンでコピーします。トークンはパスワードと同様に扱い、チャット、ソースファイル、共有設定、ログへ貼り付けないでください。エディターを再起動すると新しいトークンになります。
3. ポートを変更する場合は、**編集 → 設定... → サーバー**を開き、**MCP ポート**を変更して**サーバー設定を保存**を選びます。変更は LIBERA FX の再起動後に適用されます。再起動後に **表示 → MCP 接続...** を開き、表示されたエンドポイントを使ってください。
4. 同じパネルに **AI 操作用スキル**の欄があります。**同梱 SKILL.md**にスキルの保存場所が表示されます。対応するエージェントに導入する場合は、ローカルの保存先を指定し、**導入 / 更新**を選びます。スキルは任意の操作ガイドであり、MCP 認証の代わりにはなりません。

## クライアント設定の例

エディターに表示されている URL とトークンを使います。既定以外のポートを設定した場合は URL も変更してください。クライアントごとに設定形式は異なります。以下は現在の Streamable HTTP 設定例で、実際のトークンは含みません。

### GitHub Copilot CLI または VS Code Copilot

Copilot CLI のユーザー設定には `$COPILOT_HOME/mcp-config.json`（未設定の場合は `~/.copilot/mcp-config.json`）を使います。VS Code の Copilot も MCP サーバー設定 UI または対応する設定ファイルで、共通の `mcpServers` 形式を利用できます。

```json
{
  "mcpServers": {
    "liberafx": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "X-LiberaFx-Token": "${LIBERAFX_MCP_TOKEN}"
      }
    }
  }
}
```

エディターからコピーした値を `LIBERAFX_MCP_TOKEN` として、クライアントを起動するローカル環境に設定してください。トークンやユーザー固有の秘密情報を含む設定ファイルをコミットしないでください。設定場所や最新の項目は [Copilot MCP 設定リファレンス](https://code.visualstudio.com/docs/agents/reference/mcp-configuration)を確認してください。

### Claude Code

プロジェクト単位の `.mcp.json` では、カスタムヘッダー付き HTTP サーバーを次のように設定できます。

```json
{
  "mcpServers": {
    "liberafx": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "X-LiberaFx-Token": "REPLACE_WITH_TOKEN_LOCALLY"
      }
    }
  }
}
```

プレースホルダーはローカルで置き換えます。エディター再起動後はトークンが変わるため、未追跡のローカル設定またはユーザー単位の設定に保存し、共有プロジェクトの設定としてコミットしないでください。設定方法の詳細は [Claude Code の MCP ガイド](https://code.claude.com/docs/en/mcp)を参照してください。

## 会話の例

以下は依頼の例であり、ノード名や ID を固定するものではありません。まず現在のグラフとノード一覧を確認し、LIBERA FX が返した正確な種類・GUID・ピン ID を使うよう依頼してください。

### 簡単なエフェクトグラフを作る

> **依頼：** アクティブなグラフと使用できるノードを確認してください。小さな時間変化するパルスを提案し、既存の内容を置き換えたり削除したりする場合は先に確認してください。承認後、取得した ID とピンを使って必要なノードを作成・接続してください。
>
> **クライアント：** `libera_graph_read` でグラフを読み、`libera_graph_list_node_types` で使える種類を確認します。承認後に `libera_graph_create_node` と `libera_graph_connect_nodes` で編集し、最後にグラフを読み直して結果を確認します。

### 配線に reroute を追加する

> **依頼：** 指定した2つのノード間にある配線へ reroute を追加してください。他の接続は変更しないでください。
>
> **クライアント：** `libera_graph_read` で正確な送信元・接続先 GUID とポート ID を確認し、`libera_graph_insert_reroute` を呼び出してからグラフを再確認します。この編集はドキュメントの Undo 履歴に入り、1回分は `libera_graph_undo` で戻せます。

### ライブプレビュー中に値を調整する

> **依頼：** ライブプレビューが接続されています。`Pulse` ノードを探し、既存の intensity パラメーターを `0.75` にしてください。変更前に対象ノードとパラメーターを確認し、変更後はプレビューピアが値を更新したか調べてください。
>
> **クライアント：** `libera_preview_clients` でピアを確認し、`libera_graph_read` でノード ID とパラメーターを読みます。`libera_graph_set_parameter` で値を変更し、必要なら `libera_preview_telemetry` で利用可能な実行時サンプルを確認します。

グラフ編集はアクティブな制作ドキュメントを変更します。接続中で対応するエンジンプレビューには変更が届く場合がありますが、MCP サーバー自体がエフェクトを描画するわけではありません。エンジンのプレビューと診断表示で結果を確認してください。エンジン接続は[接続からゲームでの再生まで](production-workflow.md)、画面内の場所は[ウィンドウ・パネル一覧](editor-reference.md)を参照してください。
