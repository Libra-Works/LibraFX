# 2026.11.123 Preview

Released **2026-11-24**, following 2026.11.99.
[Download this version](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.123)
or return to [all release notes](../release-notes.md).

## What changed

- **Graph Editor & F-Curve UX:**
  - Replaced the modal `+ Add node` popup with cascading right-click submenus (`Add node -> Category -> Node`).
  - Added `Reroute` nodes (`InsertRerouteOnConnection` / `RerouteLowering`) to organize graph wires cleanly without changing compiled execution.
  - Switched MCP / auto-layout node placement to left-to-right flow without 4-column wrapping and ordered Signal pins above Parameter pins.
  - Unified F-Curve Editor pan controls (`Right` / `Middle` drag) with the Graph Editor, fixed Procedural workspace preview visibility, and added global file shortcuts (`New`, `Open`, `Save`, `Save As`, `Export`).
- **Procedural Sphere Glow & Particle Texture Defaults:**
  - Removed the built-in `RadialGlow` option from `ParticleTextureSource` and cleared the default `CpuParticleSpriteDraw` `assetPath` (`""`), preserving compatibility for existing `.lfxproj` files.
  - Added a reusable **Sphere Glow** Procedural Texture group asset (`Assets/Modules/c2000000000040008000000000000001.lfxgroup`).
- **In-App Update Checker:**
  - Added **Help -> Check for updates** and startup auto-check with release note preview and **Update now** / **Not now** / **Skip this update** choices (`AppUpdateService` / `UpdateWindow`).
- **Atomic Staging & Cross-Engine Acceptance:**
  - Added atomic `.lfxproj` / storage file writes (`WriteStorageFileAtomicallyAsync` / `WriteLocalFileAtomicallyAsync`) and verified end-to-end acceptance across LIBERA FX, Unity, Godot 4.7.2, and Unreal Engine 5.7.

## Upgrade together

1. Keep editable projects and back up existing engine bindings and installations.
2. Install the **2026.11.123 editor, converter and matching SDKs** from this release.
   Avoid duplicate Unity plugins and preserve existing `.meta` files.
3. Use `LibraForUnity-2026.11.123.zip`, `LibraForGodot-2026.11.123.zip`, or
   `LibraForUnreal-2026.11.123-UE5.7-win64.zip`.
4. Re-export and verify effects in a separate project on your intended engine and platform.
   The macOS editor app is unsigned and not notarized.
