# 2026.11.128 Preview

Released 2026-11-24. [Download this version](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.128) · [All release notes](../release-notes.md)

## What changed

- **GPU Particle F-Curve (`GpuOp.FCurve`):** Added 65-sample LUT / `LibraGpuEvalCurve_*` shader emission, `RegisterBytecode` lowering into existing opcodes (preserving the native GPU bytecode ABI), and an interactive `GpuCurveCanvas` editor in the GPU workspace inspector.
- **Particle Material & ProceduralMaterial:** Added `Material` and `ProceduralMaterial` support for CPU and GPU Particles across the editor, compilation, resource identity, and Unity / Unreal / Godot integrations.
- **Procedural Preview & Texture Workflow:** Added `NormalMap` (`LIBRA_PIXEL_NORMAL_MAP = 32`), a `Radial -> Invert -> Saturate` default procedural texture, UV checkerboard 3D model preview (`ProceduralMeshPreviewView`), live parameter updates, checkerboard toggle, drag-to-reorder & `Delete` removal, and hid `Ribbon` from the Shape UI (`Plane` default).
- **Editor & Graph UI Polish:** Preserved hierarchy camera states, fixed double-circle pin snap highlights (`PortSnapFeedback`), updated particle samples to use `ProceduralTexture` glow, added `Delete` history entry removal, enabled collapsed-state corner resizing on nested-graph nodes, replaced the `GraphGroup` `"Double-click to open"` footer with its node name, hid the idle `"Choose a node output..."` toolbar text, and added `New Graph` to the right-click menu.
- **Unreal & Godot Native Fixes:** Added the 9 missing `LibraRuntimeCore/Private` wrapper `.cpp` files for Unreal (`Verify-UnrealPluginPackaging.ps1` now enforces wrapper completeness) and fixed `SpawnableScopeKind::Instance` / `scope.containerId` in `LibraFxGodotRender.cpp`.

## Upgrade together

- Update the desktop editor, `LiberaFxConverter`, and matching engine SDKs (`LibraForUnity`, `LibraForGodot`, `LibraForUnreal`, or `LibraSDK-source`) to `2026.11.128` together.
- Back up existing projects before upgrading. The macOS arm64 desktop archive is unsigned and not notarized.
- For Unreal Engine 5.7 on Windows x64, use the prebuilt `LibraForUnreal-2026.11.128-UE5.7-win64.zip` plugin or install from source using `Install-LibraRuntimeForUnreal.ps1`.
