# 2026.11.87 Preview

Released **2026-11-23**, following 2026.11.72.
[Download this version](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.87)
or return to [all release notes](../release-notes.md).

## What changed

- **Flexible Plane Point List:** add or remove position pins on the node or in
  the inspector. Removed connections are included in undo/redo. Flexible Plane
  Draw can also export procedural texture and material connections and host
  material parameters. See [Flexible Plane Draw](../flexible-plane-draw.md).
- **Search:** find nodes and commands by their English names as well as their
  displayed language in node-adding and Anything searches.
- **GPU particle samples:** explore a Curl Noise and Turbulence particle cloud
  or particles carried by a Fluid2D velocity output. The [GPU particle guide](../gpu-particles.md)
  explains how to adjust the nodes. Their described appearance is an intended
  result, not a newly verified engine rendering.
- **Editor and SDK packaging:** Timeline, graph zoom and logging were improved.
  The Unity package includes native bridges for Windows x64, Linux x64 and
  macOS ARM64. Unreal's source SDK now includes an engine-specific binary-plugin
  build helper.

## Upgrade together

1. Keep editable projects and back up existing engine bindings and installations.
2. Install the **2026.11.87 editor, converter and matching SDKs** from this
   release. Avoid duplicate Unity plugins and preserve existing `.meta` files.
3. Use the copy-ready Unity package or the Godot addon. Godot includes a
   Windows x64 native bridge; other platforms need their own builds. The Unreal
   plugin is source-only and requires rebuilding the project's Editor target.
   The optional binary-plugin helper requires an Unreal installation and
   produces binaries for the selected engine version.
4. Re-export and verify effects in a separate project on your intended engine
   and platform. The macOS editor app is unsigned and not notarized.

## Verified for this release

- The packaging run passed MCP authoring transitions, Windows AddressSanitizer
  fixtures, Linux Clang Core/CTest, three desktop packages and engine SDK jobs.
- Downloaded artifacts passed version/revision, SDK source-hash, install-layout,
  desktop entry-point, Unix executable-bit and MSI ProductVersion checks.
  Unreal's hidden ownership manifest and Unity/Godot copy-ready files and native
  binaries were also checked. Release assets include `SHA256SUMS.txt`.

No new actual engine rendering, UnrealBuildTool, packaged player or console
validation is claimed for this release. Test the final appearance and integration
in the intended environment.
