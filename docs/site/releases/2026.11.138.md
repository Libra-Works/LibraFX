# 2026.11.138 Preview

Released 2026-11-25. [Download this version](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.138) · [All release notes](../release-notes.md)

## What changed

- **`.lfxp` is the only compiled package:** The editor, converter, MCP and live preview now produce and accept only `.lfxp` (package format 13). Legacy `.lfxb` files, the raw single-graph program API (`libra_program_create*`, `libra_session_submit_program`) and legacy preview components are removed. `.lfxproj` remains the editable authoring project; older project data is migrated when it is opened.
- **Live preview parameter deltas:** Value edits during live preview are sent as package parameter deltas with double precision, atomic validation, reset to default, enums, matrices and F-Curves, including nested graphs and group overrides. Changes that cannot be expressed as deltas, such as Signal keys, resend the full package.
- **Engine entry points:** Unreal uses `ULibraEffectComponent` as the single effect component, playing `.lfxp`. Unity and Godot import `.lfxp` only. GPU particle manifests use only the current schema.
- **Reroute and wire editing:** `Add reroute` now works. Select wires to delete them or insert reroutes in bulk, with undo. Wires stay in front of nodes while dragging into nested graphs. MCP adds reroute add, remove and inspect tools.
- **Hierarchy navigation:** Houdini-style breadcrumbs with Back/Forward history.
- **Transform node:** An optional `Parent` matrix input builds parent-child transforms without an extra `Mul` node. Behavior is unchanged when it is not connected.
- **MCP guide:** A new [MCP guide](../mcp-guide.md) explains how to connect an AI assistant and shows sample conversations.

## Upgrade together

- This is a breaking update. Update the desktop editor, `LiberaFxConverter` and matching engine SDKs (`LibraForUnity`, `LibraForGodot`, `LibraForUnreal` or `LibraSDK-source`) to `2026.11.138` together.
- Back up projects before upgrading. Previously exported `.lfxb` files and older `.lfxp` packages are not loaded by this runtime; re-export them from `.lfxproj` with this editor or converter.
- For Unreal Engine 5.7 on Windows x64, use the prebuilt `LibraForUnreal-2026.11.138-UE5.7-win64.zip` plugin or install from source with `Install-LibraRuntimeForUnreal.ps1`. No UE 5.8 binary is provided.
- The macOS arm64 desktop archive is unsigned and not notarized.
