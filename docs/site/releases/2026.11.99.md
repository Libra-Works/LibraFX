# 2026.11.99 Preview

Released **2026-11-24**, following 2026.11.87.
[Download this version](https://github.com/Libra-Works/LibraFX/releases/tag/v2026.11.99)
or return to [all release notes](../release-notes.md).

## What changed

- **Multi-platform Unity and Godot binary packages:** `LibraForUnity-2026.11.99.zip` and
  `LibraForGodot-2026.11.99.zip` now include Windows x64, Linux x64 and macOS ARM64
  native libraries with matching `.meta` / `liberafx.gdextension` configuration and
  CI binary verification.
- **Content Window and Resource Identity parity:** Unity (`Assets/`, `Packages/`) and
  Godot (`res://`) now expose `"assets"` catalog, folder, details and thumbnail browsing
  to the LIBERA FX Content Window. Godot also adds `res://` Resource Identity
  (`godot.res-path.v1` / `godot.shader-parameter.v1`) and `.lfxrm` manifest export.
  See [Production workflow](../production-workflow.md).
- **Playback and GPU blend parity:** Added `Pause()` / `Resume()` / `IsPaused` on Unity
  `LiberaFxSpawnableComponent` and `pause()` / `resume()` / `is_paused()` on Godot
  `LibraEffectPlayer`, plus `builtin:unlit-additive` blend support in Unity `LibraGpuBillboard.shader`.
- **Unreal `BuildPlugin` and local verification:** Fixed missing IWYU headers and
  `#if WITH_EDITOR` guards in `LibraRuntimeForUnreal` for `RunUAT BuildPlugin`
  (`UnrealEditor` + `UnrealGame`), and added `Tools/Invoke-LocalVerification.ps1` for
  local testing and packaging verification.

## Upgrade together

1. Keep editable projects and back up existing engine bindings and installations.
2. Install the **2026.11.99 editor, converter and matching SDKs** from this release.
   Avoid duplicate Unity plugins and preserve existing `.meta` files.
3. Use the copy-ready `works.libra.liberafx` Unity package or `liberafx` Godot addon
   (Windows x64, Linux x64, macOS ARM64). The Unreal plugin is source-only in the
   release archive; generate a compiler-free binary plugin locally with
   `Tools/Build-UnrealBinaryPlugin.ps1` if needed.
4. Re-export and verify effects in a separate project on your intended engine and platform.
   The macOS editor app is unsigned and not notarized.
