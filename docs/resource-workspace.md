# 資源ワークスペース

「コンテンツ」ウィンドウに、接続中エンジンのアセットと、プロジェクト／ローカル資源を
分けて表示します。エンジン上の実行プレビューとは別の、資源の閲覧・編集対象選択用画面です。

## 接続中エンジン

1. アセット機能を提供する接続先を選択し、名前・種類で検索します。
2. アセットを選択して、サムネイルとエンジンが返したマテリアル情報を確認します。
3. エフェクト側でノードを選択し、「割り当て先」を確認して割り当てます。

接続先にはエンジン名・ビューアー名・接続IDを表示します。複数接続時には明示的に
選択します。接続先を切り替えると、前の一覧・選択・サムネイルを破棄します。
これは接続の識別であり、永続的なエンジンプロジェクトIDではありません。

モデルはModelDraw、テクスチャはSpriteDraw／SpriteAnimationの描画アセット、
公開されたマテリアルのtextureパラメーター、GPUのTexture2D資源へ割り当てられます。
マテリアルの対象はスロット・名前・関連・インデックス、GPUの対象は資源IDで区別します。
候補が複数ある場合は未選択のままにし、先頭へ自動で割り当てません。
割り当て後のUndoとRedoは通常のグラフ履歴で行います。

モデル／スプライトの新規ノード追加も、対応する種類のアセット詳細を取得してから行います。
マテリアルアセット自体は情報の閲覧のみです。マテリアルスロットの置換は未対応です。
描画アセット全体の置換時には、既存どおり新しいスキーマにないパラメーターや接続が
除去される場合があります。個別のtextureパラメーターへの割り当てとは区別してください。

## プロジェクトのGroup

「プロジェクト／ローカル資源」タブでGroupライブラリを選択します。
選択中プロジェクトのライブラリだけを対象に、名前・種類・出所を検索できます。
出所のプロジェクト名、資源ID、リビジョン、ノード数と接続数を表示します。

Groupを選択すると、独立した読み取り専用グラフを表示します。原点から離れて保存された
グラフも全体表示します。「Groupを挿入」は、ライブラリのIDとリビジョンを保持した
通常のGroupインスタンスを、1回のUndoで戻せる操作として追加します。
プロジェクト切替やライブラリ更新時には選択を解除し、古い選択のまま挿入しません。
既存インスタンスを自動更新する機能ではありません。

## ローカルフォルダー

ローカルフォルダーを選び、「更新」で一覧を取得します。必要に応じてサブフォルダーも
検索できます。対象は `.lfxproj`、PNG、JPEGで、最大5,000件です。
隠しファイル・システムファイル・再解析ポイントは走査しません。
出所には選択したフォルダーを表示し、詳細にはファイルの場所を表示します。

エフェクトはグラフを読み取り専用で確認し、通常のプロジェクト読み込み操作で開けます。
画像は**プレビュー専用**です。ローカルファイルの絶対パスをエンジンのアセット参照として
書き込むことはありません。プレビューは最大16 MiB、画像は最大8,192×8,192です。
破損画像・上限超過は診断し、選択を切り替えた後に古い非同期プレビューを表示しません。
閲覧操作ではファイルを書き換えません。

## 対応範囲

現在の接続アセットカタログはUnreal用です。Unityのアセット探索、
エンジン／プロジェクト間の永続的なアセット対応付けは未対応です。
割り当て操作は明示的なボタン操作であり、ドラッグ＆ドロップは追加していません。
エフェクト全体の使用中アセット一覧と双方向参照索引は、別の #15 の対象です。
GitHub Pagesへの公開は有効化していません。

## 回帰確認

絶対パスの `LIBERAFX_DATA_ROOT` と隔離したビルド出力先を指定し、
`Tests\CommentImageSmokeTests.csproj` の `--resource-workspace` を実行します。
実際のウィンドウ・選択コントロール・ボタンのAutomation呼び出しを使用して、
Group挿入とUndo、原点外のグラフプレビュー、ローカルエフェクトの読み込み、
画像のプレビュー専用制約、複数GPU資源の対象選択、マテリアルtextureの個別割り当て、
接続先／プロジェクト切替時の選択解除を確認します。
エンジン応答には合成データと既存の実際のPreviewAssetStoreを使用します。

この変更では、隔離したエディター／テストのビルド、上記の専用確認、
既存スモークテスト、`--gpu-editor`、`--asset-render` を確認しています。
実ユーザーの設定・Unity／Unrealプロジェクトは使用していません。
新たなエンジンビルドや実エンジンでの表示確認を行ったことを意味しません。
