LibraGpu.Core - standalone .NET 10, no engine or package dependencies.

Public frontend contract (namespace LibraGpu.Core):
  GpuProgram: Version (1), Id, Capacity, Attributes, Resources, Kernels, Flow.
  KernelGraph: Id, Stage (Spawn/Update), Nodes, Writes.
  GpuNode: Id, Op, Type, Inputs (node IDs), Value (literal components),
    Attribute, Uniform, ComponentIndex, SourceSpan (optional UTF-16 offset/length).
  Each node has one typed output. Writes require exact attribute types.
  Graph reads evaluate against the incoming particle snapshot; stores occur last.
  IDs are descriptive strings (1..128 characters), never shader identifiers.
  Inputs/write IDs are kernel-local; kernel/resource/flow IDs are program-global.

  GpuCompiler.Parse(string, GpuLimits?) -> validated GpuProgram.
  GpuCompiler.Serialize(GpuProgram, GpuLimits?) -> canonical versioned JSON.
  GpuCompiler.Validate(GpuProgram, GpuLimits?) -> diagnostics.
  GpuCompiler.Compile(program or JSON, GpuLimits?) -> immutable CompiledGpuProgram.
  CompiledGpuProgram.EmitUsf/EmitUnityCompute/EmitHlslInclude(ShaderBindings?)
    -> ShaderSource: Text, Format, ContentHash, LineMappings, Bindings, Resources.
  CompiledGpuProgram exposes kernels, uniform/resource/flow metadata, canonical
    document SHA256, buffer bytes and optional register packets.
  Shader names are deterministic generated identifiers; metadata maps back to IDs.
  Shader export is NOT runtime execution. No engine preview is provided here.
  GetExportMetadata(format=UnityCompute, bindings?) returns backend export DTO;
    ExportMetadataJson(format=UnityCompute, bindings?) uses camelCase and enum names.
    contentHash identifies canonical IR; sourceHash identifies this exact source.

Particle ABI: stride80, five16-byte slots (LibraGpuParticle):
  0 float4 positionAge: Position.xyz, Age.w
 16 float4 velocityLifetime: Velocity.xyz, Lifetime.w
 32 float4 color: Color.rgba
 48 float4 sizeRotation: Size.xy, Rotation.z, spare.w
 64 uint4 seedAlive: Seed.x, Alive.y (0/1), spare.zw
Only these fixed attributes are supported; Quaternion is semantic and unsupported,
not an alias for float4. No host pointers, CPU Signal ops or engine objects.

Uniform ABI: constant buffer48 (LibraGpuUniforms; metadata includes shader names):
  0 capacity uint; 4 count uint; 8 spawnStart uint; 12 spawnCount uint
 16 deltaTime float; 20 time float; 24 emitterSeed uint; 28 frameIndex uint
 32 emitterPosition float3; 44 padding uint
Editable ReadUniform ops: deltaTime, time, emitterPosition.
Host must initially zero particle storage, supply finite uniforms, bind the actual
80-byte StructuredBuffer, and dispatch ordered flow with required UAV barriers.
numthreads(64,1,1), capacity-based ceil(capacity/64) dispatch-group metadata.
Spawn bounds by actual/capacity and spawnStart/spawnCount (overflow-safe).
Spawn touches only dead slots and initializes Position=emitterPosition, Age=0,
Velocity=0, Lifetime=1, Color=1, Size=1, Rotation=0, Alive=1, deterministic Seed.
Update bounds by actual/capacity/count and ignores dead slots. It advances Age
before the editable kernel unless that kernel explicitly writes Age. It does not
implicitly integrate Position; the user kernel owns motion. Invalid/nonpositive
Lifetime, nonfinite attributes, or Age >= Lifetime force Alive=0 after evaluation.
Stores preserve other attributes and spare slots during Update.

Flow v1: at most one Spawn, at most one Update, then RenderBillboard step(s).
RenderBillboard binds a declared Texture2D; an engine backend consumes the GPU
buffer directly. Compute code does not render or perform CPU per-particle work.
RenderStartTexture, ComputePass, storage textures and arbitrary buffers are
reserved with explicit unsupported diagnostics. Texture2D dimensions 0,0 mean
external; otherwise both dimensions must be positive and bounded.
Default limits: JSON4MiB/depth32/properties32, kernels64, nodes4096/kernel,
resources64, steps128, particle memory256MiB, texture texels64Mi.
Scalar broadcast: float -> float2/3/4 only, and only supported math ops; integer,
bool and vector dimension conversions are never implicit.
Division-by-zero returns zero; int MIN/-1 returns MIN. Normalize zero/nonfinite
vectors returns zero. Random hashes its explicit uint seed (not hidden host RNG).
Finite shader guards use IEEE754 exponent-bit classification, not the isfinite
intrinsic (which Unity fast-math compilation can fold without a /Gis flag).

Safe independent text frontend, same typed IR:
  GpuDsl.Parse -> GpuDslAst -> GpuDsl.Lower -> KernelGraph.
  GpuDsl.Compile(text, kernelId, stage, limits?, options?) is the shorthand.
  Grammar: immutable "let name = expression;" and sequential "@Attribute = ...;",
    +=, -=, *=, /=; xyzw/rgba component reads/writes; + - * /, unary + -,
    parentheses; float literals, signed-i/unsigned-u literals, true/false.
  dt/time/emitterPosition or param("deltaTime")/param("time")/
    param("emitterPosition"); float2/3/4 constructors, sin/cos/min/max/clamp,
    normalize/length/select/random. Select takes bool, value, value.
  No loops, arbitrary calls, declarations, shader injection or native code.
  Sequential component writes lower to Compose/Component nodes and final stores.
  GpuDsl.Emit(kernel) returns generated text plus NodeIdsBySpan/WriteIdsBySpan.
  Pass those to DslLoweringOptions when reparsing that generated limited grammar
    to retain expression IDs. This is not arbitrary text-to-visual-layout reversal.
  Node diagnostics and emitted shader line maps retain original text spans.
  GpuSamples.CreateEmitter() includes spawn, gravity, motion and lifetime fade.

Optional future fixed-interpreter export:
  RegisterKernels contain immutable typed SSA instructions; no interpreter ships.
  CompiledRegisterKernel.SerializeLittleEndian() exports bounded POD packets.
  Header64: LGPK@0, version1@4, instructionStride64@8, count@12,
    registers@16, stage@20, particleStride80@24, uniformSize48@28,
    kernelKey GUID big-endian@32, defaultAgeFlag@48, zeros@52..63.
  KernelKey preserves GUID IDs, otherwise SHA256(UTF8 ID) first16 canonical bytes.
  Instruction64: uint opcode@0,dst@4,a@8,b@12,c@16,type@20,aux@24,d@28;
    float4 immediate@32; uint4 exact integer/bool payload@48.
  Missing registers=UINT_MAX; aux is attribute/uniform slot or component index.
  Compose uses a/b/c/d. Stores use a and aux with no destination. Constants use
    float or integer payload according to Type, never lossy packed float casts.
  No separate constant table is needed: constants are embedded instructions.
  Opcode/type enums have stable explicit numeric values. An interpreter backend
    must implement the same typed broadcast/math and host lifecycle as HLSL.

Common math/noise extension (append-only opcodes, version1 packet unchanged):
  Opcode18 remains WriteAttribute and is NOT a GpuOp.
  19 Abs, 20 Floor, 21 Ceil, 22 Round, 23 Frac, 24 Mod, 25 Sign,
  26 Pow, 27 Sqrt, 28 Exp, 29 Log, 30 Lerp, 31 Smoothstep, 32 Remap,
  33 Dot, 34 Cross, 35 Distance, 36 Saturate,
  37 GradientNoise3D, 38 Fbm, 39 Turbulence, 40 CurlNoise.
  All new ops use aux0, destination typed as below, and no immediate payload.
  Unary uses a; binary a/b; ternary a/b/c; fractal noise a/b/c/d.
  None use casts or packed float encodings for UInt seeds / Int octaves.
  Old opcode/type values, particle/uniform/packet layout and lifecycle unchanged.
  Backends MUST reject new opcodes until implemented, not silently treat as old.

Typing / operand order:
  Abs/Sign: input/result matching numeric Float/Float2/3/4/Int/UInt.
  Floor/Ceil/Round/Frac/Sqrt/Exp/Log/Saturate: input/result matching Float*.
  Mod: numeric arithmetic-broadcast rules (same as old Add/Div).
  Pow(a,b), Lerp(a,b,amount), Smoothstep(edge0,edge1,value): Float* scalar
    broadcast, all vector dimensions must match, result same widest Float*.
  Dot: matching Float2/3/4 a,b -> Float (no broadcasting).
  Cross: Float3 a,b -> Float3, right-handed.
  Distance: matching Float/Float2/3/4 a,b -> Float (no broadcasting).
  Remap: a=value Float*, b=sourceRange Float2, c=targetRange Float2;
    source/target x,y mean min/max. Same scalar ranges apply to every value lane.
    This is an UNCLAMPED remap, not a five-operand instruction.
  GradientNoise3D: a=position Float3, b=seed UInt -> Float.
  Fbm/Turbulence/CurlNoise: a=position Float3, b=seed UInt,
    c=octaves Int1..8, d=gain Float0..1.
    Fbm/Turbulence -> Float; CurlNoise -> Float3.

New math policies:
  New Float math guards return zero per lane for nonfinite input/result.
  Dot/Cross/Distance reject the entire nonfinite input vector, return zero.
  Abs(Int MIN)=MIN (wrapping), Sign(Int/Float)=-1/0/1, Sign(UInt)=0/1.
  Round is nearest, ties-to-even. Frac(a)=a-floor(a), including negative inputs.
  Mod is remainder with dividend sign (not positive modulo); divisor0 ->0,
    Int MIN%-1 ->0. UInt values remain exact 32-bit integers.
  Pow negative base requires exact integer exponent, otherwise0; 0^0=1,
    0 to a negative exponent=0. Nonfinite/overflow results ->0.
  Sqrt nonpositive ->0; Log nonpositive ->0; Exp is natural exponential.
  Lerp is not clamped. Smoothstep equal edges ->0, otherwise clamped
    normalized value then t*t*(3-2*t); reversed edges invert the transition.
  Saturate clamps to0..1. Remap equal source endpoints ->0.
  Existing operations0..17 retain existing math policies.

Original deterministic 3D noise (no external/proprietary implementation):
  Gradient lattice hashes integer xyz and explicit UInt seed. Six unit-axis
    gradients, quintic interpolation, exact analytic spatial derivatives.
  GradientNoise3D output [-1,1]; integer lattice points have scalar value0.
  Fbm uses frequency2^octave, amplitude gain^octave and hashed per-octave seeds.
    Weighted sum normalized by amplitude sum, output [-1,1].
  Turbulence is normalized weighted ABSOLUTE gradient noise, output [0,1].
  CurlNoise computes analytic curl of three independently seeded FBM scalar
    potentials. It is NOT normalized random vectors or a finite-difference hack.
    Constant-per-parameters scale weightSum/(16*frequencyWeightSum) preserves
    divergence-free behavior in the finite interior. Components lie [-1,1];
    vector magnitude is NOT normalized to1 (conservative bound sqrt(3)).
    The divergence-free guarantee holds for fixed spatial seed/octaves/gain;
    varying those parameters with position is not the curl of one fixed field.
  Domain: every coordinate finite, |coordinate| <= 1048576 for base noise.
    Fractals require |coordinate| <=1048576/2^(octaves-1), so all octave
    lattice conversions remain bounded/exact enough for float32 arithmetic.
    Out-of-domain, invalid octaves/gain, or nonfinite inputs ->zero.
    Domain cutoffs are guards, not a claimed divergence-free boundary condition.
  Octaves are statically unrolled1..8 only; dynamic invalid counts return0.
    Literal out-of-range octaves/gain are compile diagnostics with input spans.
  Frequency/amplitude are composable external math; default space frequency1,
    amplitude1, seed0, octaves4, gain0.5. Use scalar spatial frequency for
    divergence-free uniform scaling; arbitrary anisotropic warps need care.

Shared frontends / support / verification:
  Descriptor DisplayName, DslName, Inputs (Id,DefaultType,DefaultValue,
    OptionalInDsl,Minimum,Maximum) are immutable machine-readable palette data.
  GpuOperationRegistry.TryInferType/TypesMatch share compiler shape rules.
  GetDefaultInputs(op, preferredResult=Float) returns valid typed defaults.
  Safe DSL uses lowercase names, including gradientnoise3d/fbm/turbulence/
    curlnoise; noise optional arguments materialize as ordinary constant nodes.
    E.g. curlnoise(@Position) -> position3, seed0u, octaves4i, gain0.5.
  Graph -> generated DSL -> typed IR preserves mapped node IDs for new ops too.
  Shaders\LibraGpuSupport.hlsl is the original shared portable helper include;
    GpuShaderSupport.EmitHlslInclude() returns identical embedded source.
    Interpreters may include/copy it, but remove duplicate old helper definitions.
    All kernels exported by ShaderEmitter embed this support automatically.
  GpuNoise/GpuMath are CPU numerical references for validation, NOT a CPU
    particle runtime or automatic engine fallback.
  CreateNoiseProbe/CreateNoiseGuardProbe/CreateMathProbe produce validation IR.
    MathProbe has18 separate kernels; default flow references abs only. A harness
    can select each kernel by metadata ID and reset inputs before dispatch.
  Test --export also writes noise.reference.json/math.reference.json expected
    buffer data, six curl-neighbor samples, tolerance/epsilon, and shared include.
  Tests check analytic derivatives, seed variation, lattice continuity, ranges,
    finite/domain/parameter guards and div(curl) using central differences h.001.
    Measured CPU reference max divergence: ~4.1e-5 across25 probes.
  Strict installed-DXC checks now cover69 entries (all formats, old+new fixtures).
  Separate backend verification: Unity7000.0.0a16 / D3D11 / RX6700 XT passed16
    noise cases and54 math cases across18 kernels, guard/seed/range checks and
    curl central-difference divergence -1.0e-5. The library remains source-export;
    runtime execution belongs to that backend, not CompiledGpuProgram itself.
