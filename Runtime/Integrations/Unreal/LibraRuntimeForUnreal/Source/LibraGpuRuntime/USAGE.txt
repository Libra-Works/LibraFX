Libra GPU Unreal integration (experimental, requires UE 5.7 SM5).

For whole effects, use ULibraEffectComponent with a .lfxp Package. It owns
CPU/GPU/Spawnable playback together; no separate author-added GPU component is
required. The APIs below describe the low-level helper and standalone
experimental .lfxgpu path retained for compatibility and diagnostics.

Import a .lfxgpu JSON bundle created by LibraGpu.UnrealExport or the frontend
gpu_export_bundle tool (programSequence/nodeId/canonicalJson/metadata/shaderSource/
registerKernels[{id,stage,base64}]/resourceAssetPaths). No packet re-lowering or
external converter is required. Each texture binding must explicitly select
builtin:white or resolve to UTexture2D at import; the resulting
ULibraGpuEffectAsset holds hard UObject references for real texture assets and
a serialized discriminator for the engine's runtime white texture. Missing
bindings never silently fall back to white. Invalid replacement packets and unresolved
texture references leave an existing asset's program unchanged. Core's generated
USF is retained as source export, not executed.
FlowMap2D resources use the same UTexture2D binding. SampleFlowMap decodes RG
from [0,1] to [-1,1]; Float2 coordinates are UVs and Float3 coordinates use
the resource's selected world-axis pair and bounds. Any Texture2D can be
assigned, with Linear vector data recommended.

ULibraGpuEffectRuntime is an internal UObject, not an actor component.
ULibraEffectComponent owns and ticks it for standalone effects; Spawnable and
editor preview owners drive their own runtimes. SoftEffect is loaded with the
engine streamable manager. The owner actor location supplies emitterPosition;
the owning tick supplies time and deltaTime. Each runtime holds separate GPU
buffers. The execution mode is the fixed GpuRegisterInterpreter shader:
it executes validated LGPK packets, not per-asset generated HLSL. Packet limits
are 256 registers per kernel, 64 kernels, and 256 MiB total particle and
per-particle register storage. StorageTexture2D/Buffer resources and
unsupported pass kinds fail
import. Asset changes are snapshotted at ResetEffect and do not mutate a running
render-thread instance.

Billboards are instanced directly from the particle GPU buffer in a post-tonemap
view extension. This initial pass is unlit and does not depth-test, sort
transparency, participate in shadows, or evaluate native UE material graphs.
Texture2D bindings and actual alpha/additive fixed-shader presets are supported.
It must not be presented as a production renderer.

Additive renderer contract (root of either bundle/delivery JSON, ABI/version1 unchanged):
  "rendererBindingsVersion": 1,
  "rendererBindings": [
    {"flowId":"renderStep","renderer":"builtin:billboard",
     "material":"builtin:unlit-alpha","sizeScale":100}
  ]
When present, supply exactly one entry for each metadata.flow RenderBillboard
id, and no unknown/duplicate flow entries. Only builtin:unlit-alpha and
builtin:unlit-additive are supported; the latter actually changes GPU blend
state. /Game material paths and unknown renderer/material tokens reject
atomically. Legacy absent renderer fields retain alpha and sizeScale1.
sizeScale is an optional finite float, 0<sizeScale<=10000, multiplying quad
half-extents only. It is NOT simulation/position/velocity/physics-unit conversion.
Rendering uses UE world centimeters and the runtime supplies native world XYZ
to emitterPosition. Canonical CreateEmitter Size0.1 is therefore subpixel at
ordinary UE camera distances without an explicit scale. A UE starter can
explicitly choose sizeScale100 (10cm half-extents); its velocity3 remains
3cm/second along UE Y, not a silently converted meters/Y-up simulation.

Runtime GetPreviewBounds(FBox&) returns false when LocalPreviewBounds is
invalid/unknown. An explicitly supplied conservative emitter-relative
LocalPreviewBounds is shifted by owner actor translation into world space;
it is not readback, alive-particle bounds, or inferred arbitrary-IR bounds.
For the canonical starter with sizeScale100, an explicitly selected
[-100,+100]cm box covers its lifetime/gravity/quad extent. Preview owners must
route Frame to this box only when their authored bounds/policy is known.
Preview cache/reuse identity must include full rendererBindingsVersion and
rendererBindings: changing alpha/additive/sizeScale must replace the snapshot.

Engine shader support: SM5 or later. Runtime modules have no UnrealEd dependency;
global shaders are cooked by the engine shader pipeline, not generated on load.
The runtime uses engine-bundled OpenSSL only for SHA256 integrity checks.
Native asset data validation checks packet bounds, inactive fields, types, flow,
hard dependencies, and exact SHA256 canonical-IR/source integrity.

Example focused cook (engine command line, use your own project paths):
  UnrealEditor-Cmd.exe Project.uproject -run=Cook -TargetPlatform=Windows
    -Map=/Engine/Maps/Entry -CookDir="Project\Content\LibraFXSamples"
    -unattended -stdout -FullStdOutLogOutput
Cook the owning map or specify the effect's content directory; a loose soft
reference is not automatically a primary asset cook rule. Hard texture
dependencies are retained by UPROPERTY references. Gameplay may use cooked
hard references or cooked soft references selected by game content/cook rules.

and standalone DXC compilation are not evidence of Unreal GPU execution.

Append-only interpreter extension source now implements opcode19..40: numeric
Abs/Sign/Mod; guarded float Floor/Ceil/Round/Frac/Pow/Sqrt/Exp/Log/Lerp/
Smoothstep/Remap/Saturate; typed Dot/Cross/Distance; GradientNoise3D, FBM,
Turbulence and analytic CurlNoise. StoreAttribute remains opcode18. Quaternion,
custom attributes, arbitrary loops, texture compute and unknown opcodes fail.
The shared helper is generated byte-for-byte from GpuShaderSupport.EmitHlslInclude
into Shaders/Private/LibraGpuSupport.ush. It is not an independently rewritten
noise implementation. All packet aux/type/operand/literal bounds are checked.
Noise octave/gain runtime guards return zero outside their supported domain.
Analytic curl is divergence-free only for spatially fixed seed/octaves/gain,
inside the documented bounded coordinate domain.

Live-preview owner integration (game thread, module dependency LibraGpuRuntime):
  auto candidate = ULibraGpuEffectAsset::CreateInMemory(owner, compiledBundleJson, error);
  if (!candidate) return; // Keep the previous effect/component unchanged.
  if (!component->SetEffect(candidate)) return;
  component->ConfigureEmitter(100, 1);
  component->Play();
CreateInMemory accepts the exact gpu_export_bundle frontend DTO or .lfxgpu
exporter envelope. It validates packets/source hashes/resources atomically,
loads only typed texture dependencies on the game thread, and needs neither
UFactory nor disk package creation. Component Effect holds the candidate as a
hard reference. ValidateProgram(error), GetCapacity, GetKernels/GetFlow/
GetTextures and GetContentHash/GetSourceHash are public. Engine frame/tick
ordering dispatches plain snapshots only; no UObject traversal occurs on RT.
Changing an existing asset does not mutate the running snapshot: call
ResetEffect or SetEffect+Play after an accepted update. The transport owner
must reject stale programSequence messages and route container IDs; this
module does not flatten graph children or own the existing editor transport.
